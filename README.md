# Anti-Error

A fast, browser-based static code analyzer that detects bugs, errors, and security issues in your code instantly. No installation, no server - everything runs 100% in your browser.

## Live Demo
[Try Anti-Error Live](anti-error.netlify.app)

## Features
- Instant bug & error detection
- Security vulnerability scanning
- Code quality analysis
- Auto-fix suggestions
- Supports multiple file types and code snippets
- 100% private - your code never leaves your browser
- No sign-up required

## How to Use
1. Open the live demo
2. Paste your code or upload a file
3. Click **Analyze**
4. Review errors, warnings, and suggested fixes
5. Copy the corrected code

## Supported Analysis
- Syntax errors
- Undefined variables & logic bugs
- Common security risks
- Bad practices & code smells
- Performance issues

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

Built as a single-file web app for speed and portability.

## Why Anti-Error?
Most analyzers require installation, accounts, or sending your code to a server. Anti-Error runs locally in your browser, making it fast, free, and private for developers, students, and teams.
